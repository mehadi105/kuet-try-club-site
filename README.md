# TRY Club KUET Website

This project is a basic website for the TRY Club of KUET, developed using HTML and CSS. TRY is a voluntary social service club that represents initiative, effort, and the spirit of taking action for positive impact.

## Project Objective
The goal of this project is to design a simple, clean, and responsive website that represents the club’s activities, members, and events.

## Planned Features
- Home page with overview
- About section describing the club
- Events section to showcase activities
- Members section
- Contact page

## Technologies Used
- HTML (structure)
- CSS (styling and layout)

## Project Status
